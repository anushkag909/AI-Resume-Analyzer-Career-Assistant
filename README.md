# AI Resume Analyzer & Career Assistant

An AI-powered application designed to analyze resumes, extract relevant information, identify technical skills, and assist users in understanding their career profile.

## 🚀 Overview

AI Resume Analyzer & Career Assistant is a Python-based application that helps users analyze their resumes and gain insights into their professional profiles. The application extracts information from uploaded resumes and presents relevant details to support career development.

## ✨ Features

- 📄 Resume upload and parsing
- 🔍 Extract relevant information from resumes
- 💼 Technical skills identification
- 🎓 Extract education, projects, certifications, and experience
- 📊 Resume analysis and insights
- 🤖 AI-powered career assistance

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- spaCy
- PyMuPDF
- pdfplumber
- Pandas
- NumPy

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/anushkag909/AI-Resume-Analyzer-Career-Assistant.git
```

### 2. Navigate to the project folder

```bash
cd AI-Resume-Analyzer-Career-Assistant
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
